# ghp-faceplate-tool

This repository provides a backup deployment of the GHP Faceplate Customization website for troubleshooting, testing, and validation.

## Official Website

https://ghp-faceplate-tool.grandstream.com/#/ghp61x

## About This Repository

- The contents of this repository are copied from the compiled `dist` output of the GHP Faceplate Customization project. The project source code is not included.
- This repository provides a backup address for the website through GitHub Pages.
- The backup page is intended for verifying fixes and testing changes. It is not a replacement for the official website.
